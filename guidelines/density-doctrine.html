Dense system, simple product.

Every component carries its full capability; every screen uses the minimum of it. A view earns density only when the user asks for it.

The disclosure ladder

  1. Glance — decision-level only: a Badge, one number, a PulseDot. "In review · KD 38"
  2. Hover — one layer deeper: Tooltip, ChartTooltip, full timestamp.
  3. Click — everything: Modal / detail view, all MetricChips, history.

Per-view budgets

  • 1 brand-green CTA per view
  • ≤ 4 scorecards — the fixed spine, nowhere else
  • ≤ 3 MetricChips visible per item — rest behind +N or the detail view
  • 1 meter column per table; numbers stay bare in cells
  • 1 chart per card; machine facts run tabular-nums in the one family — mono is retired

Base type is 13.5px, and it works because air lives at the edges, not between rows — generous card padding, dense row rhythm. Widening row gaps to feel "premium" just makes a dense screen tall.
