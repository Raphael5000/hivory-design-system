The sorted column carries full ink and an arrow; sorting is a header click, focusable and keyboard-fired.

Empty & loading
Empty states speak in two lines — what this is, and what fills it. Never an illustration. First paint uses Skeleton rows in the same grid; in-flight refreshes keep the old rows and settle the new ones in with a crossfade.
Guidelines

The discipline.

Do
Right-align every numeral, mono and tabular. One meter column per table, at most. Badges ride inside cells for status. Bulk actions live once in the header. Flush to the card edge when the table is the card.
Don't
Vertical rules or zebra stripes — the grid is alignment, not boxes. Center-aligned numbers. More than seven columns (disclose instead). Rows that move on hover — tint, never lift. Green header text.

The eight states
Every interactive component provides all eight or declares which do not apply, with the reason. A silent omission is the bug this table exists to prevent.
Rest Uppercase header at 10.5/700, hairline rows, numerics right-aligned with tabular-nums. Rows 38–46px.
Hover Row takes --hover-on-white. Only the row — cells never hover independently.
Pressed brightness(0.94) from motion-base when the row is a link.
Focus motion-base ring on the row, not the cell. A row that opens something is one focus stop, not one per column.
Selected Clickable rows: --ink-50 fill, held while the panel it opened stays open, so the client can see what they are looking at.
Disabled n/a a row is data. A record that cannot be acted on keeps its row and loses its verb.
Loading Header renders real; body becomes Skeleton rows at the SAME row height, so the table does not resize when data lands.
Empty One sentence in a full-width row saying what will appear and, if relevant, the action that fills it. Never a centred illustration and never “No results found” — say what was searched.
Content rules
Headers are one or two words, sentence case, never “#” or an abbreviation the client has not seen elsewhere. Numeric columns are right-aligned and labelled with their unit in the header, not in every cell. Truncate honestly — “Showing 6 of 118”, never a silent cut. Empty cells use an em-dash, never “N/A” or “0”, because zero is a measurement and absence is not.
