Design System
Component · Spinner & PulseDot

Alive, not anxious.

The activity primitives. The Spinner is the mark itself — two hexagons counter-rotating while work is in flight. The PulseDot breathes for things that are simply on. In an agent console, these are load-bearing.

Which primitive?
Spinner for discrete in-flight work — a publish, a sync, a call. PulseDot for ongoing aliveness — agents running, a live connection. Skeleton for first paint. Never two spinners in one view.
Guidelines

The discipline.

Do
Pair with a label saying what is happening ("Publishing…"), and a time hint when you have one. Calm tempo for anything over ~10 seconds. Green only for agent/brand work; ink for the mundane. Honor reduced motion — both primitives freeze.
Don't
Generic ring spinners — the mark is the spinner. A spinner where a Skeleton belongs (first paint). Naked spinners with no label beyond icon size. PulseDot as a status badge — it means alive now, not "positive".
Tokens used
3 tokens, read from the component's stylesheet. This is the contract: change one of these and the component changes everywhere.
Ink --ink-300--text-muted
Type --font-sans
Three tokens only, and none of them motion — the counter-rotation is authored in the component’s own keyframes. That is a gap: it should consume --duration-spinner so the cycle can be tuned in one place.
Variants
Tones brand · ink · on-dark, with an optional label. `calm` slows the cycle for long-running agent work. Rule of thumb: Spinner for discrete in-flight work, PulseDot for ongoing aliveness, Skeleton for first paint.
The eight states
Every interactive component provides all eight or declares which do not apply, with the reason. A silent omission is the bug this table exists to prevent.
Rest Two counter-rotating hexagon outlines echoing the dual-hex mark, in 60° gear-click steps over --duration-spinner, seamless via six-fold symmetry.
Hover n/a an indicator, not a control.
Pressed n/a
Focus n/a never focusable. Its accessible name lives on the region it describes, announced politely so a screen reader is not interrupted every cycle.
Selected n/a
Disabled n/a
Loading This IS the loading state — the component only exists while work is in flight, which is why it must never be left mounted after it resolves.
Empty n/a no work means no spinner.
Content rules
The label is present-tense and plain-language, saying what is happening rather than that something is: “Reading memory…”, “Building…” — never “Loading…” or “Please wait”. It may morph as phases change. One line, never stacked.
