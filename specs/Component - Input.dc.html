Guidelines

The discipline.

Do
Prefer inline in the product. Reach for the filled field only when a field must stand alone. Recessed at rest, white on focus, one crisp green ring, green caret. Error in plain language under the field.
Don't
A hard bordered rectangle. A coloured focus glow. Standalone fields where an inline edit belongs. Placeholder used as the label.

Focus is expressed as a --green-600 inset ring, not a halo: motion-base owns the focus outline system-wide, and two rings on one field was a real bug (fixed 31 Jul).
Variants
Input · Select (chevron, no free text) · Textarea (min-height 72, resize vertical). Each takes label, hint and error. Error replaces hint — never both at once.
The eight states
Every interactive component provides all eight or declares which do not apply, with the reason. A silent omission is the bug this table exists to prevent.
Rest 34px field, --radius-control, 1px --border-strong inset ring on --surface-card, caret --green-500.
Hover Ring deepens to --ink-300 at --duration-soft. The label never moves.
Pressed n/a a field is not pressed; clicking it focuses it.
Focus Ring goes 1.5px --green-600 INSET. There is no 3px halo: motion-base owns the outline, and running both drew two rings on one field (real bug, fixed 31 Jul).
Selected n/a text selection inside is the browser’s, not a component state.
Disabled --ink-50 fill, --text-faint text, cursor not-allowed. A disabled field keeps its value visible — hiding it loses the reason it is disabled.
Loading n/a a field being validated stays editable. Blocking input to show a spinner loses keystrokes.
Empty Placeholder only, in --text-faint: an example of the answer, never a restatement of the label.
Content rules
Label is a noun, sentence case, no colon: “Full legal name”. Placeholder shows the SHAPE of a valid answer (“Maya Osei”), never repeats the label and never says “Enter…”. Hint is one clause of help that is always true. Error names what to do, not what went wrong: “Add the name as it appears on the agreement”, not “Invalid input”. Never validate while someone is still typing.
