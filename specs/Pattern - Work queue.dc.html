Pattern · Queue table

Three questions, one table.

What needs you, what's moving, what shipped — one quiet grid answers all three. State lives in a 2px edge line, channels in a glyph, and there is no sort control: state → time is the sort.

One header row, groups as sections inside — never separate cards. The 2px edge line is the only state ink: amber needs you, green is running now (“running” breathes — the table's only animated text).
The grammar

Rows that earn their ink.

Time · Job · Channel · Status
Sentence-case 12/500 headers — no shouting caps in the header row; the caps register belongs to the state sections. Single-line 13.5/500 titles, stacked tabular time (today a clock, other days a date), the quiet Channel chip, and a Status slot that holds one thing or nothing: the Review verb, or a word that adds real information.
No dots, no agent, no provenance
Dots spent a column saying what the section already says — the 2px edge line carries state for free. The agent never mattered to the client. And the “from session” link lives inside the opened job, where the question actually gets asked.

Search glyph · borderless input · live “n of total” + ✕ · one Filter Select per dimension (Status · Channel) — multiselect dropdowns, never a row of option pills. Filtering keeps only matching sections. A sorter is banned — state → time is the sort.
Guidelines

The discipline.

Do
One table card, sections inside — consistency beats elevation. Edge lines only where state demands attention. Rows open their job in place; the queue stays behind the panel. Archive completed work behind “View all — N ›” past 100 rows.
Don't
State dots or per-group cards. Colored channel pills — the glyph differentiates. Option pills strewn across the header — filters live in Filter Selects. An agent column. Outcome metrics in Completed. Sort controls, or a weekday posing as a date.
