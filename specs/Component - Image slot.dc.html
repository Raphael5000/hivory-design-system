Variants

Shape follows the destination.

rect — feed media, hero images
rounded — library tiles, cards
circle — a person
fit="contain" — logos and marks, never cropped
The default is cover — the picture fills the frame, because the frame is the destination's real shape. contain is for artwork whose edges are the point: a lockup, a mark, a diagram. Getting this backwards is how a client's logo ends up cropped in their own brand kit.

Attributes

Six, and one of them is mandatory.

{{ a.k }} {{ a.v }}
The slot fills its container by default, so the parent owns the aspect ratio. Give it explicit width and height only for a genuinely fixed-size slot such as an avatar.
Content rules

The placeholder is a brief.

Say what belongs there and, where it matters, at what size: “Post image · 1200 × 627”, “Primary lockup”, “Founder portrait · 4:5”. Never “Upload image”, “Drop file here” or “No image” — the drop behaviour is already obvious from the frame, and the one thing the client cannot guess is what this particular picture is for. Sentence case, no full stop, no verb. Dimensions use × not x, and only when the destination genuinely constrains them.
Do
Give every slot a distinct, stable id — that is what makes a dropped picture survive a reload. Let the parent set the ratio. Use the destination's real proportions. Say what the picture is for.
Don't
Reuse an id across surfaces — two slots sharing one id share one picture. A slot inside a mock's inert chrome. Stock photography as a placeholder image. contain on photography, or cover on a logo.
