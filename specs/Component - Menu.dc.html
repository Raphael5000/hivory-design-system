Anatomy
Card radius 12, 5px inner padding, 32px items, mono shortcut hints right-aligned. Destructive actions sit below a hairline separator, tinted red only on hover.
Guidelines

The discipline.

Do
Fade + rise from the trigger, 180ms. Destructive below a separator. Verb labels, mono shortcuts. Close on Esc or click-away — with the same soft fade out.
Don't
Slide, bounce, or spring it open. Snap in with no transition. Mix delete with safe actions. Nest submenus deeper than one level.

Variants
Row menu (actions on an object) · schedule menu (opens ABOVE its trigger, for publishing verbs) · with a danger zone below a separator. Destructive items always sit last, after a separator, never inline among neutral ones.
The eight states
Every interactive component provides all eight or declares which do not apply, with the reason. A silent omission is the bug this table exists to prevent.
Rest Floating card at --radius-xl on --shadow-overlay, 5px padding, rows 12.5px in --ink-900.
Hover Row takes --ink-50; the wash is the full row width, not the label.
Pressed brightness(0.94) from motion-base.
Focus motion-base ring on the row. Arrow keys move focus; Esc closes and returns focus to the trigger.
Selected A check glyph in the marker column — never a filled row, which reads as hover.
Disabled Row at opacity .45, still announced, still in the DOM. A menu that hides unavailable actions teaches nothing.
Loading n/a a menu opens with its items known. An async menu shows its trigger as loading instead.
Empty A single --text-faint line saying why there is nothing (“No other agents available”). Never an empty floating card.
Content rules
Each row is a verb phrase naming its consequence, sentence case, two to four words. Order is repair → neutral → destructive, matching the colophon. A row that opens a confirmation still reads as the verb (“Delete template”) — the modal carries the warning, not the menu. No icons unless every row has one.
