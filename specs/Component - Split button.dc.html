Component · Split button

Approve now, or on your terms.

Every publishing verb in the console is a split button: the main segment approves with the default schedule, the chevron opens the alternatives. It exists so the common case takes one click and the rare case still takes one menu — never a dialog.

There is no outline, ghost or danger split. A split button always ships something — if the action is reversible or secondary it does not earn two segments, and a destructive action must never hide alternatives behind a chevron.
Sizes

Two rungs, both Button's.

The split button borrows Button's ladder rather than inventing one, so a split and a plain action sit at the same height in the same footer. There is no lg split — a hero CTA is a single decision, and offering a schedule menu on it would undercut the moment.

This component adds no chrome of its own: the segments are Button and the panel is Menu, both at their published values. The divider is an inset box-shadow at 18% white, not a border — a border would add a pixel to the object's width and break the pill's symmetry.
Content rules

The label names the default.

The main segment says the verb and its real consequence — “Approve & publish”, “Approve & send”, “Commit & publish” — never “release”, never “Submit”. It never describes the chevron: no “Approve & publish ▾”, no “…options”. Menu rows are the alternatives in plain words, ordered soonest-first: Publish now · Best slot — <date time> with “Your top-performing slot” beneath · Pick a date & time… (the only row that earns an ellipsis, because it opens something). Every choice resolves to the same confirmation the plain Button gives: “✓ Added to the Work queue — <schedule>”.
Accessibility

Two tab stops, not one.

Both segments are real button elements and both take a tab stop — collapsing them into one stop would make the alternatives unreachable. The chevron carries aria-haspopup="menu", aria-expanded and its own label (“Choose when to publish”), because a chevron glyph alone announces nothing. The menu is role="menu" with role="menuitem" rows; Enter and Space activate, Esc closes and returns focus to the chevron. Disabling disables both segments — an open menu on a dead button offers choices that cannot happen.
Do
Put the most common schedule in the main segment. Open the menu upward — a split button lives in a footer, and a downward menu would leave the viewport. Keep the divider inset. Give the chevron its own accessible name.
Don't
A caret in the label. A destructive split. More than three menu rows — beyond that the alternatives are a screen, not a menu. Different consequences in the two segments: the chevron changes only when, never what.
