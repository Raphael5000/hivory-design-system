Guidelines

The discipline.

Do
Let the tint + tone-coloured label carry the state. A bare coloured word in dense rows. One word per state. Green only for live/running/approved. Counts grey.
Don't
A dot inside a tinted badge (redundant). A pill / max radius. A coloured count. Green as decoration. Animating anything but the live signal.
Tokens used
12 tokens, read from the component's stylesheet. This is the contract: change one of these and the component changes everywhere.

Type --font-sans
All four status pairs are consumed together — a badge that hard-codes one tone is the common misuse. No motion: only the live signal animates, and that is PulseDot.
Variants
Five tones: positive · info · caution · negative · neutral, each with and without a leading dot. Tone comes from the --status-* pairs only — never a hand-mixed wash.
The eight states
Every interactive component provides all eight or declares which do not apply, with the reason. A silent omission is the bug this table exists to prevent.
Rest Tinted wash plus its matching text token from ONE --status-* pair, 21px tall at --radius-sm.
Hover n/a a badge reports; it never responds. If it needs hover it is a Channel Chip or a Button.
Pressed n/a same reason: nothing to press.
Focus n/a not focusable. A badge in the tab order is a keyboard trap that leads nowhere.
Selected n/a selection belongs to the row.
Disabled n/a a status cannot be disabled. Something inactive takes the NEUTRAL tone; it is never a faded badge.
Loading n/a the row shows a Skeleton. A badge whose state is unknown is omitted, never rendered blank.
Empty Omitted entirely. A badge with no status is not a neutral badge — it is no badge.
Content rules
One or two words, sentence case, no punctuation, never a verb. It names a state the reader can act on or wait for — “Held for you”, “Live”, “Revising”. Never a count, a percentage or an ID; those are data and belong in a cell. Never restate what the section header already says: inside a FOR YOUR REVIEW group, “Needs review” is noise.
