The Markdown Kit

.md files are a platform primitive — every source, document and the memory itself IS one, and renders through exactly these pieces. The kit is judged on whole files, not fragments: two composed specimens below, then the vocabulary. Rules that never bend: reading measure 620 · body 13.5/1.7 · a fixed 20px marker column against a constant 6px gutter (the gutter, not the left edge, is what the eye reads) · exactly two heading levels per file · green marks structure and memory events only · every fact carries provenance · every line is editable, and an edit is a learning. Kit law: a file is either live (header, facts, entries — read & fix) or a draft (adds md/updated, md/question, md/draft-bar — nothing applies until approved). No third state, no other components. Agents never emit UI — they emit typed content; the kit renders it. Nothing enters memory without being shown; ambiguity becomes a question; every fix is a learning.
